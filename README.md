## 📌 About
A production-ready Machine Learning web app that predicts traffic congestion for Visakhapatnam based on location, time, weather, and historical traffic data. Includes a **live Google Maps** view of the selected location.

## 🧠 How it works
- **Machine Learning:** Random Forest Regressor trained on 100,000+ synthetic data points mimicking Vizag traffic patterns.
- **Features:** Location, Time, Day, Weather, Previous Traffic, and Holidays.
- **Visuals:** Interactive Plotly Gauge, Google Maps embed, and detailed reports.

## 📍 Locations Covered
Gajuwaka, NAD Junction, Maddilapalem, Siripuram, MVP Colony, Dwaraka Nagar, RTC Complex, Jagadamba Junction, Akkayyapalem, Madhurawada

## 🛠️ Tech Stack
- Python, Pandas, NumPy
- Scikit-learn (Random Forest)
- Plotly (Traffic Gauge)
- Streamlit (UI & Deployment)
- Google Maps Embed (Live Location)
